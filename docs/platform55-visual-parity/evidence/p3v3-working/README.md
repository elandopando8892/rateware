# P3-V3 working visual evidence

This directory contains local, non-release evidence for the five Procurement and Carrier Network routes.

- `*-loaded-1440x900.png`, `*-loaded-1024x768.png`, and `*-loaded-390x844.png` are implementation captures from the deterministic read-only fixture.
- `platform55-build05-wireframe-*.png` are responsive source captures from the supplied Build 05 HTML.
- `comparison-*-1440x900.png` and `comparison-*-390x844.png` place source and implementation together on a normalized canvas for visual review.
- `comparison-vendors-390x844.png` intentionally uses the responsive Build 05 source. The fixed 1920 Service 360 image remains the desktop Carrier CRM identity/detail reference.

These files are working evidence only. They do not grant release credit and do not replace an immutable browser-certification manifest or independent review.
